# Семинар 7. Многопоточное умножение матриц

Изучение технологии многопоточности (`std::thread`, `std::atomic`) на примере
умножения матриц `A = B * C` из семинара 6. Код ускорялся поэтапно с помощью
ИИ-чата по промптам из задания, затем проверялся и замерялся.

## Задача

| Этап | Что делается | Функция |
|------|--------------|---------|
| 1 | Однопоточное умножение (i, k, j) с таймером `high_resolution_clock`, n = 800 | `run_stage1`, `run_single` |
| 2 | Потоки `std::thread`, строки делятся между потоками, «наивный» замер (с созданием потоков) | `run_stage2`, `run_threads_naive` |
| 3 | Атомарный флаг `std::atomic<bool>` + `this_thread::yield()`, замер только вычислений | `run_stage3`, `run_threads_flag` |
| 4 | Таблица n = 300, 500, 800, 1500: 1 поток против 4 потоков (закон Амдала) | `run_stage4` |
| 5 | Потоки с флагом, но медленный порядок (i, j, k) | `run_stage5` |
| 6 | Итоговая таблица всех вариантов и ускорение относительно этапа 1 | `run_stage6` |

## Сборка и запуск

Требуется: g++ (C++17), CMake 3.16+, WSL Ubuntu или Linux.

```bash
cmake -S . -B build          # настройка (по умолчанию Release, -O2)
cmake --build build          # сборка с -Wall -Wextra -Wpedantic -Werror
./build/manual_tests         # проверочные сценарии
./build/sem7 --stage 1       # этап 1 (n = 800)
./build/sem7 --stage 4       # этап 4 (таблица размеров)
./build/sem7 --stage 6       # итоговая таблица
./build/sem7 --stage 6 --n 500   # другой размер матриц
```

Параметры: `--stage 1..6` (по умолчанию 6), `--n 1..3000` (по умолчанию 800).
Каждый замер — среднее из 3 запусков после одного прогревочного.

## Способ обработки ошибок

Во всём проекте используется **значение-маркер `std::optional`**: функции,
которые могут не выполниться (создание матрицы, запуски умножения, разбор
параметров), возвращают `std::nullopt` при некорректных данных. Функция
`multiply_rows` и функции этапов возвращают `bool` (`false` — ошибка).
Программа никогда не падает на неверном вводе: печатается сообщение и справка,
код возврата `1`.

Проверяется: размер `n` вне диапазона 1..3000, нечисловой параметр, неизвестный
параметр, параметр без значения, пустые матрицы, матрицы разного размера,
0 потоков, диапазон строк за пределами матрицы. Если потоков больше, чем строк,
их число уменьшается до `n`.

## Функции

| Модуль | Функция | Назначение |
|--------|---------|------------|
| matrix | `is_valid_size` | проверка размера матрицы |
| matrix | `make_random_matrix` | матрица n x n со значениями 0..9 |
| matrix | `multiply_rows` | умножение строк [begin, end) в порядке (i,k,j) или (i,j,k) |
| matrix | `matrices_equal` | поэлементное сравнение результатов |
| parallel | `hardware_threads` | число потоков устройства (`hardware_concurrency`) |
| parallel | `run_single` | этап 1: один поток + таймер |
| parallel | `run_threads_naive` | этап 2: потоки, таймер включает их создание |
| parallel | `run_threads_flag` | этапы 3, 5, 6: потоки ждут атомарный флаг |
| parallel | `measure_thread_overhead` | время создания и `join()` пустых потоков |
| experiments | `run_stage1` … `run_stage6` | выполнение и печать этапов |
| cli | `parse_options`, `print_usage` | параметры командной строки |

## Проверяемые сценарии (`tests/manual_tests.cpp`)

1. Известный результат: `{1,2,3,4} * {5,6,7,8} = {19,22,43,50}`.
2. Типичный случай n = 64: порядки (i,k,j) и (i,j,k), потоки наивно и с флагом
   дают одинаковую матрицу.
3. Граничные случаи: n = 1; 8 потоков при n = 3 (работают 3 потока).
4. Некорректные данные: n = 0, n = −5, пустые матрицы, разные размеры,
   0 потоков, диапазон строк за пределами матрицы.
5. Параметры командной строки: `--n abc`, `--n 0`, `--stage 9`, `--speed 1`,
   `--n` без значения отклоняются; `--stage 3 --n 500` принимается.
